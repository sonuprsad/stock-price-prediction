# 📈 Stock Price Prediction using Deep Learning

## 🚀 Overview
This project predicts stock prices using LSTM (Deep Learning).

## 🧠 Tech Stack
- Python
- TensorFlow / Keras
- Streamlit
- Pandas, NumPy, Matplotlib

## 📊 Features
- Upload CSV dataset
- Real-time visualization
- Technical indicators (MA, EMA, RSI)
- Buy/Sell/Hold prediction

## 🖥️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
